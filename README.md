# 就活リスタートAI (Restart Note)

就職活動の選考で不採用（お祈り）を受け取り、精神的に落ち込んでいる大学生の「感情整理」から「失敗の構造化・自己分析の再定義」「次の企業への再挑戦」までを一気通貫で支援する、スマホアプリ風の対話型AIプロトタイプWebアプリケーションです。

---

## 📱 アプリ概要
* **対象ペルソナ**: 
  * 「第一志望」の企業で「最終面接（役員面接）」に落ちてしまった大学生
  * 「自分の人格や大学4年間すべてを否定された」ような自責感と絶望感に襲われ、部屋のカーテンを閉め切って毛布で震えている状態
* **コア体験**:
  * 説教や正論・安易な励まし（「次頑張ろう」等）を一切言わず、絶望感を徹底傾聴・全肯定
  * 非就活的なメンタルケア処方箋の提案
  * 提出ESと役員面接の詰まりデータの客観的カウンセリング
  * カルチャー不一致の言語化 ➔ 企業推薦軸・フィルターへの自動変換 ➔ 役員面接リベンジ対策

---

## 🌟 3ステップの機能構成

### ① 感情受容モード（フェーズ1）
* **深い傾聴と全肯定**: 悔しさ、怒り、恥ずかしさ、孤独感を一切否定せず傾聴。
* **自責・自己否定の検知**: 「4年間全否定」「自分が無能」などの自責感情を検知し、心理的負担を軽減（「あなたは絶対に悪くないよ」）。
* **非就活メンタルケア処方箋カード**: スイーツ、長めの入浴、8時間以上の睡眠を提案し、心身の回復を最優先。

### ② 状況整理・深掘りカウンセリングモード（フェーズ2）
* **提出ES・ガクチカの深掘り**: 役員面接まで残ったエピソードから「本当に好きだったこと・関心の原点」を抽出。
* **役員面接の問答分析**: 企業側から何が問われ、どこで手こずったのか（トップダウン・数字至上主義への拒絶反応）を客観的に構造化。
* **弱点分析 ＆ 自己分析アップデートカード**: 人格否定を解体し、「カルチャーの根本的不一致」と「真の強み（伴走型エンパワーメント力）」を再定義。

### ③ 再行動支援モード（フェーズ3）
* **カルチャー不一致 ➔ 企業推薦軸・検索フィルター自動変換**: あなたが活きる組織風土（自律分散・ボトムアップ・加点方式・HRTech）のフィルターを生成。
* **厳選おすすめ企業3選カード**: あなたの強みを評価してくれる企業をピックアップ。
* **役員面接リベンジ必勝武器カード**: 前回の詰まりを強力な差別化ポイントに昇華する志望動機テンプレート。
* **模擬面接 ＆ 弱み重点フィードバック講評カード**: 弱み克服度（98点）の講評。

---

## 🚀 使い方
1. ブラウザで `index.html` を開きます。
2. 画面右上の **「▶ デモ再生」** ボタンを押すと、ペルソナに沿った一連のカウンセリング対話が自動実演されます。
3. 入力欄上のクイックチップや自由入力、音声入力マイクを使って、手動で対話を体験することも可能です。
